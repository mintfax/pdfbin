§0Quick start

Pin a fixture by its flat URL. Bytes are immutable - the same URL returns the same PDF forever.

curl
curl https://pdfbin.net/xref-truncated.pdf \
  -o fixture.pdf
Python (pytest fixture)
@pytest.fixture
def truncated_pdf(tmp_path):
    url = "https://pdfbin.net/xref-truncated.pdf"
    return urlretrieve(url, tmp_path / "f.pdf")[0]
JavaScript
const url = "https://pdfbin.net/aes256-owner.pdf";
const blob = await (await fetch(url)).blob();
